#  Scan bite

**Scan bite** is a web-based food label analyzer that helps users understand what's inside packaged foods. Using OCR (Optical Character Recognition), the application scans ingredient labels, identifies potentially harmful additives, allergens, preservatives, and ultra-processed ingredients, then generates a personalized health grade based on the user's profile.

---

##  Features

*  Scan food labels using your camera
*  Upload one or multiple ingredient label images
*  Extract text using **Tesseract.js OCR**
*  Detect allergens, preservatives, artificial colors, and additives
*  Personalized analysis based on health conditions and allergies
* Automatic food grading system (A–E)
* Scan history tracking
* Educational food facts and ingredient insights
*  Optional AI-assisted ingredient recognition
* Personal diet plan based on bmi and health records

##  How It Works

1. Upload or capture an image of a food label.
2. OCR extracts the ingredient list.
3. Label Lab analyzes ingredients against its built-in database.
4. The system checks for:

   * Allergens
   * Artificial additives
   * Preservatives
   * Sweeteners
   * Health-condition triggers
5. A detailed report and grade are generated instantly.

##  Health Personalization

Users can create a profile containing:

* Allergies
* Diabetes
* Hypertension
* Kidney Conditions
* IBS / IBD
* PCOS / PCOD
* Thyroid Disorders
* High Cholesterol
* Pregnancy
* ADHD Sensitivity
* gout
* And more

The grading system adapts recommendations based on the user's profile.

---

##  Grading Scale

| Grade | Meaning                         |
| ----- | ------------------------------- |
| A     | Excellent ingredient quality    |
| B     | Generally healthy               |
| C     | Moderate concerns               |
| D     | High processing or risk factors |
| E     | Significant health concerns     |
